# PRD — 通用导入 + 导入归类弹窗（D49/D50）

> 决策来源：`DECISIONS.md` D49（通用导入）、D50（归类弹窗——D5「导入时手动分类」自 2026-08-21 定盘以来首次真正落地）。
> 词汇：归类 / 包内分类 / 按文件夹名归类 / 统一归入 / 待分类（见 CONTEXT.md）。

## 前置依赖（必须在 crud 之后动工）

- 归类弹窗「统一归入」新建/选择的分类落库复用 crud 的 `set_category` 窄列 UPDATE 通路。
- 回收站已落地：导入枚举与派生侧过滤走 `for_each_asset_active`，本任务不得再引入无过滤扫描。

## Goal

导入入口统一化 + 每批一次的归类确认弹窗：用户可以混选素材文件与 .emo 包一次导入；可以把文件/文件夹直接拖进窗口导入；导入前弹窗按来源给出最合理的默认归类解释，回车即走默认。

## Requirements

### 通用导入（D49）

- R1 主导入按钮升级为**文件对话框多选**：可同时混选素材文件（png/jpg/…按 media 注册表 D23）与 `.emo` 包；混选集合按扩展名分发到 D24 `PackageRegistry`（素材文件 = DirectoryReader/单文件路径，.emo = EmoReader）——管线层已就绪，本任务只扩收集层。
- R2 保留现有「导入文件夹…」与「导入 .emo 包…」入口（D35/D36 不动作语义），三入口最终汇入**同一条**归类弹窗 + 子进程导入管线。
- R3 **窗口拖拽导入**：把文件或文件夹拖到应用窗口任意位置即触发导入（走同一弹窗+管线）。前置 spike：Slint 1.17 原生 OS 文件拖入（取路径列表）能力查证；无现成支持则 platform 层 `RegisterDragDrop` 兜底（D16 装配边界不变，trait 收口 `platform`）。
- R4 拖入内容含不支持类型 = 静默跳过该文件（与现 enqueue `Unsupported` 语义一致），零散文件与 .emo 混拖合法。

### 导入归类弹窗（D50）

- R5 所有导入入口**统一弹窗、每批一次**；弹窗出现在起子进程**之前**；「取消」= 放弃本次导入，零文件进库。
- R6 选项按来源条件化，默认项恒为该来源最合理解释，**回车即走默认**：
  - `.emo` / 千牛结构目录：「按包内分类」（默认，groupName，标注「含 N 个分类」——N 需在起弹窗前低成本预扫描包得到）/「统一归入 ▼」/「放入待分类」。
  - 普通文件夹：「按文件夹名归类」（默认）/「统一归入 ▼」/「放入待分类」。
  - 零散文件（含混选中的散文件部分）：「统一归入 ▼」（默认选中「待分类」）/「放入待分类」。
  - 混选 = 多来源并存时按来源分组各给一行选项（一组一个归类决策），弹窗仍一次。
- R7 「统一归入 ▼」= 已有分类下拉 + 输入新名即新建；选定的分类名随行传给导入子进程（现 `ImportRequest.category` 已支持显式分类，D29 RuleChain 的 explicit 优先）。
- R8 ☐「记住我的选择，不再询问」：勾选后同来源类型不再弹窗直接套用；记住的是**方式**（按包内/按文件夹名/待分类），方式为统一归入时连**分类名**一并记住；设置面板新增恢复询问入口（沿用 D28 SETTING_SPECS 描述化机制）。
- R9 「按文件夹名归类」= 现 RuleChain ParentDirectoryRule 语义；「按包内分类」= GroupNameRule（.emo groupName / 千牛结构目录名）；「放入待分类」= 强制 INBOX。弹窗的三种方式映射为显式指令传给管线，**不得**再依赖静默 RuleChain 兜底（D50 落地后静默归类只作为「记住」路径的实现细节）。

## Constraints

- C1 D7 入库模型不变：复制入库、异步拷贝队列、pHash 去重；弹窗不得把导入做同步阻塞。
- C2 UI 进程零解码零全量扫描（D11/D3）：预扫描包内分类数 N 仅读目录结构/.emo 清单（D24 reader 元数据），不解码媒体。
- C3 弹窗与既有弹层同一渲染纪律（Flickable 内浮层先例）；出场/入场动效直接采用 motion 子任务的两段式模式（motion 排最后做，但**新弹层出生即正确**——本任务先行实现下一帧翻转入场 + 两段式出场，motion 负责回改旧三处与统一）。
- C4 D16：拖放兜底若落 platform 层，Win32 具体类型只出现在 `win32_runtime_deps()`。

## Acceptance Criteria

- [ ] 混选 3 素材 + 1 .emo 一次导入成功；.emo 内素材带包内分类、散素材进所选统一分类。
- [ ] 弹窗取消 = 库零变化（无半成品行、无孤儿 objects/）。
- [ ] 三来源默认项与 D50 表逐条一致（VM 纯函数穷举测试：来源 → 默认选项 + 选项集）。
- [ ] 「含 N 个分类」计数正确（.emo 与多子目录文件夹各测）。
- [ ] 记住选择：重开应用后同来源不再弹窗；设置恢复询问后重新弹。
- [ ] 拖拽导入闭环（spike 结论决定原生或兜底路径，两条都算交付）。
- [ ] 全量三道门绿；D49/D50 落地回写 DECISIONS.md。
