# PRD — 动效与瀑布流收尾：动画修复包 + 底边补齐（D53/D54）

> 决策来源：`DECISIONS.md` D53（动画修复包）、D54（瀑布流底边漏补）。
> 排程：批 1 最后执行。三处新弹层（crud 右键菜单/操作条、import 归类弹窗、search 范围下拉）已按「下一帧翻转入场 + 两段式出场」模式出生即正确；本任务负责 **回改旧三处弹层 + 瓦片淡入 + 底边修复 + 动效纪律统一**。

## Goal

用户可感知的动效缺陷清零：入场动画全部真实生效、出场有淡出、缩略图「闪烁」变「浮现」、瀑布流触底瓦片无需二次滚动。

## Requirements

### 动画修复包（D53）

- R1 **入场根因修复**：三处弹层（目标下拉 :821 / 导入菜单 :927 / 设置面板 :973）的「init 置 shown」技巧改为挂载后下一帧（16ms Timer）翻 shown——首帧以 opacity 0 渲染再过渡。Slinit init 回调跑在首帧之前，旧写法下 150ms 过渡从未发生（根因已在 DECISIONS 定案，勿再怀疑设置项）。
- R2 **出场两段式**：先翻 `shown=false` 播 150ms 淡出，Timer 到点真正卸载 `if` 块；期间再次开合 = 取消挂起卸载（状态机含 pending-close，防连点鬼影）。
- R3 **瓦片缩略图淡入**：D43 渐进装载 `set_row_data` 换图时 150ms opacity 淡入（「闪烁」→「浮现」），仅对从无图→有图的替换生效，不随滚动重播。
- R4 **开关钳制**：全部动效受既有 `ui_animations` 设置钳制（关 = 0ms 直达终态，含 Timer 段一并跳过）。

### 瀑布流底边补齐（D54）

- R5 fill 停表条件从「当前窗口缺图补完」（thumbs.rs:192-195 `built.missing == 0 → return`）加「几何稳定」判据：本轮滚动位置（`get_content_y()`）与上轮一致才允许停表；不一致则再排一轮 fill（静止后至多多跑一轮空 pass）。
- R6 触底惯性回弹期间内容高度/窗口位置变化不得漏补：静止后底边瓦片自动显形，**无需用户再滚动**。
- R7 修复不得引入常态开销：无缺图且几何稳定 = 一次布尔比较即停表（fill 链不在常态路径产生额外读盘/解码）。

## Constraints

- C1 纯壳层/Slint 任务：零数据层改动（grid_vm::ensure_window 语义不动，D43 驻留守卫必须继续绿）。
- C2 定时器只用 `slint::Timer`/SingleShot（线程内事件循环，零新线程）。
- C3 动效不得改变上框时序：Timer 回调里不做 paste（D44/D45 行为零变更）。
- C4 `--bench` D43 驻留守卫与 window_spec 全部既有测试绿为硬验收。

## Acceptance Criteria

- [ ] 三处旧弹层入场可见淡入（目测 + 若可自动化：首帧 opacity==0 断言）。
- [ ] 出场淡出可见；连点开关无鬼影/无残留浮层（pending-close 状态机单测或逻辑走查）。
- [ ] 缩略图替换淡入生效；滚动浏览不重播已显示图。
- [ ] ui_animations=false 时全部动效直达（Timer 不排、过渡 0ms）。
- [ ] 真机复现路径回归：万级库滚动到底松手不回弹再滚——底边瓦片自动显示（用户冒烟）。
- [ ] 三道门绿；D53/D54 落点回写 DECISIONS.md。
