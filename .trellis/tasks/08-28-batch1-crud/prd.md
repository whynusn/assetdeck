# PRD — 素材 CRUD：回收站 + 多选模式 + 右键菜单（D46/D47/D48）

> 决策来源：`DECISIONS.md` D46（回收站）、D47（多选）、D48（右键菜单五项）。
> 词汇：回收站 / 彻底删除 / 多选模式（见 CONTEXT.md，禁用「垃圾桶」「真删除」「批量模式」）。

## Goal

把库内素材的删除、批量选择与常用整理动作做进 UI：单张/多张删除进回收站（软删、可恢复、可彻底删除、可清空）；修饰键 + 显式多选模式；瓦片右键菜单五项（复制 / 移动到分类 / 重命名 / 属性 / 删除）。

## Requirements

### 删除 = 库内回收站（D46）

- R1 删除（单张或多张）= 移入库内回收站：meta.db 打 tombstone 标记 + 正本目录 `objects/<uuid>/` 移入 `trash/<uuid>/`，不硬删。
- R2 回收站内容**不占**浏览、分类计数、搜索、导出、派生（缩略图/pHash 回填）等一切正常视图；派生工序必须跳过回收站条目。
- R3 支持「恢复」：重进索引与正常视图；支持「彻底删除」：索引 + meta.db 行 + `trash/<uuid>/` 下正本与派生全清，不可恢复。
- R4 「清空回收站」是手动动作；**不做自动过期清理**（勿实现）。
- R5 回收站入口 UI 存在且可操作（侧栏系统项或等价入口，具体形态 design 定），其中可逐条/批量恢复与彻底删除。
- R6 既有「清空整库」（DangerButton）语义保持为全清（连同回收站），不留孤儿。

### 多选（D47）

- R7 修饰键多选：Ctrl+点选 = 切换选中；Shift+点选 = 锚点到当前的范围选；Ctrl+A = 全选当前视图。修饰键不可用时（Slint TouchArea 限制）须有等效可达路径（见红线 B）。
- R8 顶栏「选择」按钮进入**多选模式**：期间单击 = 选中/取消，双击无操作；底部浮出操作条「已选 N 张｜全选｜移动到分类｜删除｜取消」。
- R9 退出多选模式（再点「选择」/ Esc / 操作条「取消」）清空选区、恢复常态。
- **红线 A（D47 模式红线）**：多选模式期间 D13 双击上框**完全屏蔽**——模式存在的唯一意义。
- **红线 B（D13 不回归）**：常态下单击/双击上框链路一字不变（含 D44 再断言、D45 连击合并语义）；任何多选改造不得触碰注入序列。
- 推迟（本任务不做）：橡皮筋框选。

### 右键菜单（D48）

- R10 瓦片右键弹出菜单，恰五项：**复制**（素材进剪贴板 = 上框语义止步处，同 D13 不回车）、**移动到分类**、**重命名**、**属性**（尺寸/大小/导入时间/路径）、**删除**（进回收站）。
- R11 「移动到分类」作用于当前选区（无选区时作用右键命中瓦片）= 批量归类的 UI 入口，是 A4（D5 积压缓解）第一半。
- R12 重命名只改显示名（file_name），不动库内 `objects/<uuid>/raw.<ext>` 路径；FTS 触发器保证改名后检索自动一致。
- R13 属性面板字段如实展示，路径展示绝对路径（D14 教训）。
- 后续计划不入本任务：编辑标签（动工前先查证标签写回层级）、大图预览浮层。

## Constraints

- C1 D10 内存预算：tombstone 位图每 100 万条 ≤ ~125KB（Roaring），不得为回收站引入全量元数据常驻。
- C2 D16 装配边界：新增 UI 能力若需 OS 调用（如「复制」复用剪贴板），只能在两处 `win32_runtime_deps()` 装配；`layering_guard.rs`/`deps_guard.rs` 白名单不变。
- C3 D11 进程模型：派生工序（derive-thumbs/worker）跳过回收站 = 只读查询过滤，不得新增 UI 进程解码。
- C4 schema 迁移：新列须走 `PRAGMA user_version` 迁移（v3→v4），老库无损升级、可打开。
- C5 行为变化走 trait、UI 表现走数据字段（DECISIONS 第五节原则）。

## Acceptance Criteria

- [ ] 删除→回收站→恢复：全链路测试（store 软删/恢复、视图过滤、tombstone 位图）绿。
- [ ] 彻底删除→ `trash/` 目录与 meta.db 行同灭；清空回收站批量执行。
- [ ] 回收站素材不出现在：浏览网格、分类计数、搜索（含 FTS5 路径）、导出包、derive-thumbs 回填范围——各有守卫测试。
- [ ] 多选模式：模式内点击改选区、`paste_asset` 恰零调用；退出清空选区——`grid_vm`/编排层测试。
- [ ] Ctrl/Shift 多选与 Ctrl+A 语义纯函数测试（选中集状态机可单测，不依赖真实按键）。
- [ ] 右键菜单五项齐备；「复制」不产生 Enter；「移动到分类」批量生效且分类名→id 映射随重载正确。
- [ ] 重命名后 FTS 命中新名、不再命中旧名（store_spec 扩展）。
- [ ] 老库（v3）打开自动升 v4，计数不变。
- [ ] `cargo test --workspace` / `clippy -D warnings` / `fmt --check` 全绿；D13/D16/D45 既有守卫无一退红。
