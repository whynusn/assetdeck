# 主题包

应用随附「深色」「浅色」和「桃桃猫」。深色、浅色的色板编译进程序；桃桃猫是可替换的外置主题包。打开「设置 → 主题」选择后立即生效，选择会写入 `settings.toml`。修改或新增包后，点击「重新读取主题目录」。目前没有文件变更自动监听。

## 安装和制作

复制 `_template` 目录，改成自己的主题 ID（例如 `my-theme`），并把 `theme.toml` 中的 `meta.id` 改成同一个值。ID 长度为 2–32 位，只含小写英文字母、数字和连字符，开头不能是连字符。`_template` 和 `builtin-` 开头的目录不会被扫描。

把主题目录放在以下任一位置：

- **个人主题**：与当前素材库的 `settings.toml` 同级的 `themes/<id>/`。没有指定素材库时，使用程序目录下的 `themes/<id>/`。
- **随程序分发**：`asset-manager.exe` 同级的 `themes/<id>/`。便携包和安装包均带此目录。

同 ID 的个人主题优先于随程序分发的主题；深色和浅色内置主题不会被覆盖。主题被移走或校验失败时，应用回退深色，并在设置面板显示错误。旧设置文件只有 `light_theme` 而没有 `theme_id` 时，仍按原来的深浅选择启动。

`theme.toml` 的 `[palette]` 是完整色板，38 个核心颜色必须全部填写；缺键、拼错键和非法颜色都会拒绝整包。颜色支持 `#rgb`、`#rrggbb`、`#rrggbbaa`。复制模板后可改动以下维度：

| 维度 | 当前支持范围 |
|---|---|
| 配色 | 自绘界面的语义色、文字、表面、状态徽标；有对比度校验 |
| 几何 | 圆角、部分控件尺寸、文字行高、瓦片间距、密度阶梯 |
| 字体 | 已安装的系统字体、整体字号比例、展示字号、字距 |
| 图标 | 线条图标的描边粗细、线帽、默认尺寸 |
| 动效 | 开关、三档时长和 `ease-out` / `linear` 缓动 |
| 装饰 | PNG 背景、角饰、水印和贴纸；当前最多两张图片 |

当前 Slint 标准控件只跟随主题声明的 `base = "dark"` 或 `"light"`，无法读取自定义色板的每个颜色。系统标题栏仍跟随 Windows。`line-height`、`bg-app-alt`、`filled` / `pixel` 图标集和声音目前不生效，因此加载器会明确拒绝这些选项。装饰图须为 PNG，单张不超过 512 KiB，宽高各不超过 1024 px；`theme.toml` 不超过 64 KiB。每个扫描目录最多选取按名称排序的前 32 个主题目录，合并后最多保留 32 个外置主题。

背景图固定在素材视口，滚动不会将图片拉伸到整个素材库的高度。角饰、水印和贴纸放在侧栏的专用装饰带，`x` / `y` 相对于该装饰带，避免覆盖素材正文或拦截点击。个人主题建议放在素材库目录，程序升级会更新随程序分发的主题。

## 素材与许可

装饰图路径必须相对于主题目录，不能穿出包目录。含素材的随附主题须提供 `THIRD_PARTY.md`，逐项记录文件、来源网址、作者、许可证和获取日期；需要随附原始许可证文本时一并放入包内。项目的发布许可策略见 `automation/theme-system/theme-spec.md`：只采用允许商业使用、来源可核查的素材，不使用商业角色 IP 或来源不明的图片。「桃桃猫」所用素材与许可证记录在 [`peach-cat/THIRD_PARTY.md`](peach-cat/THIRD_PARTY.md)。

主题解析和路径校验在载入阶段完成；若图片虽通过基础 PNG 结构检查、却无法由渲染器解码，启动和目录重载时会提示错误并回退深色；手动切换失败则保留原主题和选择。装饰图片应压缩后再使用，以控制常驻内存。
